# Code of Conduct

## Our standard

GradeForge is an open source educational tool built for students, teachers, and developers. I want this project and its discussions to be welcoming, helpful, and respectful to everyone, regardless of experience level, background, or identity.

## Expectations

- **Be respectful and constructive**: Give honest, useful feedback on issues and pull requests.
- **Help newcomers**: Many students making their first open source contributions will start here. Be patient and helpful.
- **Focus on the project**: Keep discussions focused on improving GradeForge, fixing bugs, and supporting students.
- **Zero tolerance for harassment**: Trolling, insults, personal attacks, or discriminatory comments will not be tolerated.

## Enforcement

If you run into behavior that violates this code of conduct in issues, PRs, or discussions, please report it to me directly via [my portfolio](https://poorvithmp.com) or open a private issue. I'll review it and take appropriate action, including removing comments or blocking accounts from the repo.
